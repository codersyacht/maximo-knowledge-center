# Create Users

### Author: Mohamed Jawahar Hussain

## Introduction

Create a new user account.

## Prerequisite

Not applicable

## Execution Steps

- Navigate to Access and Usage -> Users
- Click Create Users

|Attribute| Value     |
|---------|-----------|
|User Id| jawahar|
|Display Name|jawahar|
|Person ID|Generate using User ID|
|Primary email|md.jawahar@codersyacht.com|
|Primary email type|WORK|
|Storeroom site for self service requisitions|BEDFORD|
|Default site| BEDFORD |
|User Default Site as a Display Filter| Enable|
|Access to Inactive Sites|Enable|
|System Account For Manage|Enable|

- Under Authentication choose User Name as Same as User ID, Password as Custom.
- Enter New Password and Confirm Password.

- Under the 2. Access & license, select all applications.
- Match the default application settings and other settings as that of maxadmin.
